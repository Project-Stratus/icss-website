Guides and resources for each project. We're still putting these together.

Until the guides are up, here's where to start for each project:

  • Tycho: the 4-week Rocket Engine Design Crash Course, where you design your own engine
  • Svarog: freshers' projects on how to design, build and test satellite systems
  • Stratus: electronics, radio and the reinforcement-learning controller
  • IPRL: Triton's three intro research projects in the first term
  • High Powered Rocketry: OpenRocket, and the 2023 flight computer on GitHub
  • Mini Rover: end-to-end rover design for first-timers

Stratus code lives on the Project-Stratus GitHub. If you've written a guide that should go here, email space.society@imperial.ac.uk.
